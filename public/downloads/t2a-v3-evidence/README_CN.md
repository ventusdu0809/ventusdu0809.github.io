# T2A Evaluation Program v3 公开证据

本目录对应研究版本 `v3.2.3 r2` 与审计修订 `r3`。

主要文件：

- `T2A_Evaluation_Report_v3.2.3_r3.md`：当前正式项目报告；
- `T2A_Audit_Release_Record_r3.md`：公开审计说明与方法边界；
- `T2A_Audit_Revision_Notes_r3.md`：r3 整改记录；
- `controlled_comparison_summary_v3.2.3_r3.json`：受控比较摘要；
- `multilabel_badcase_summary_v3.2.csv`：全局多标签 Badcase；
- `badcase_conditional_rate_v3.2.3.csv`：条件发生率；
- `badcase_persistence_960.csv`：Prompt × 模型 × 标签的 Persistence 记录；
- `repeat_consistency_v3.2.3.csv`：隐藏重复一致性及敏感性分析；
- `sao1_historical_bridge_v3.2.csv`：Phase 1–Phase 2 非等价历史桥接；
- `audit_manifest_sha256_v3.2.3_r3.txt`：审计 ZIP 内部 Manifest；
- `T2A_v3.2.3_r2_audit_r3.zip`：public-safe 审计与复现包；
- `SHA256SUMS.txt`：本公开目录文件校验清单。

公开材料不包含原始 WAV、私人 blind map、隐藏重复身份映射、访问令牌或个人源路径。人工听评、Badcase 语义诊断和最终裁决仍是感知与语义结论依据。
