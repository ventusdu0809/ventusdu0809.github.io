# Phase 1 → Phase 2 Bridge Note

## Status

Phase 1 (SAO1 Single-Model PoC v1.3) was completed and archived as the first evaluation phase.
Phase 2 (SAO1 vs SA3M Controlled Comparison v2.0.3) has been completed as of 2026-07-25.

## What Changed

1. **Phase 1** established the evaluation framework:
   - 40-prompt test set with 5 fixed seeds
   - OVL/REL rubric with event-level diagnostics
   - Five-layer diagnosis pipeline
   - Blind review with 20 hidden repeats
   - Formal adjudication workflow

2. **Phase 2** extended the framework to controlled model comparison:
   - SAO1 was regenerated as a fresh v2 baseline
   - SA3M was generated with the same prompts
   - 400 samples were jointly blinded and rated
   - 40 hidden repeats tested intra-rater consistency

## Data Boundary

- Phase 1's 200 formal samples are NOT merged into Phase 2's model comparison statistics.
- Phase 1 serves ONLY for:
  - Method evolution documentation
  - Historical baseline portability analysis
  - Demonstrating that historical scores cannot be unconditionally used as new baselines
- Phase 2 v2.0.3 is the authoritative source for all formal model comparison conclusions.
