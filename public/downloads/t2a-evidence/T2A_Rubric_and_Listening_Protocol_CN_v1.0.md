# T2A 人工听评 Rubric 与 Listening Protocol

版本：v1.0  
适用范围：Stable Audio Open 1.0 的 200 条正式 T2A 音效样本及 20 次隐藏重复听评

## 1. OVL：整体音频质量

OVL 在隐藏 Prompt 的条件下评分，避免文本预期提前影响对声音本身的质量判断。

| 分数 | 锚点 | 判定说明 |
|---:|---|---|
| 1 | 不可用 | 静音、严重噪声或削波，或存在明显生成失败。 |
| 2 | 较差 | 勉强可辨，存在严重伪影、中断或明显不自然。 |
| 3 | 基本可用 | 存在瑕疵，但作为生成音效仍具使用价值。 |
| 4 | 良好 | 整体自然、完整，仅有轻微问题。 |
| 5 | 优秀 | 接近可直接进入项目使用。 |

## 2. REL：文本—音频相关性

REL 在显示英文 Prompt 后复听并评分；英文 Prompt 是正式语义参照，中文仅作辅助理解。

| 分数 | 锚点 | 判定说明 |
|---:|---|---|
| 1 | 无关 | 核心声源错误，或音频与 Prompt 几乎没有对应。 |
| 2 | 弱相关 | 仅大类相符，核心事件模糊或缺失。 |
| 3 | 核心匹配 | 核心事件正确，但属性、数量或时序存在重要缺失。 |
| 4 | 大部分匹配 | 核心事件清楚，大部分属性与事件关系正确。 |
| 5 | 高度匹配 | 核心事件、音色或属性、数量与时序几乎全部满足。 |

REL 是独立的 1–5 分人工评分，不由事件级诊断字段机械求和或平均得到。

## 3. 实际听评顺序

1. 仅显示 Blind ID，隐藏 Prompt；允许重复播放，先评 OVL。
2. 显示英文 Prompt，重新播放音频并评 REL。
3. 在复听后填写主事件、次事件、属性、时序、数量等事件级诊断。
4. 结合听感、事件级证据与文件检查记录最终人工决策。

## 4. Listening Protocol

| 项目 | 实际条件 |
|---|---|
| 环境 | 安静的室内环境 |
| 监听设备 | Beyerdynamic DT 770 PRO X |
| 音频接口 | MOTU M4 |
| 播放与复听软件 | Adobe Audition |
| 播放电平 | 固定系统音量；未做标准化声压级（SPL）校准 |
| 会话规模 | 每批约 30 条 |
| 会话时长 | 每批约 45 分钟 |
| 休息 | 批次间约 15 分钟 |
| 总进度 | 两天完成 220 次盲听：200 条正式样本 + 20 条隐藏重复 |
| 重复播放 | 允许 |
| Prompt 可见性 | OVL 阶段不可见；REL 阶段显示英文 Prompt |
| 事件诊断 | 在显示 Prompt 并复听后填写 |

未做标准化 SPL 校准意味着本项目不能声明跨实验室、跨设备的绝对播放声压可比性。固定系统音量用于减少同一评测流程内的非必要变化。

## 5. 隐藏重复与复测口径

- 隐藏重复共 20 条，不进入正式 200 条统计。
- 主复测口径仅采用两次评价顺序间隔不少于 30 的 15 对。
- 该结果反映同一评测人的复测稳定性，不是多人评测一致性。

## 6. 最终决策边界

以下边界是对本次 adjudicated 数据与人工决策的**事后归纳**，不是预注册阈值，也不是自动决策规则：

| 决策 | 本次数据中的事后归纳 |
|---|---|
| `pass` | 核心使用要求与主要语义已满足；允许存在不影响核心判断的轻微记录问题，因此不等于“零缺陷”。 |
| `keep_as_badcase` | 输出仍可辨认和分析，但存在数量、时序、属性、空间或局部伪影等具有诊断价值的问题，保留用于专项分析与回归测试。 |
| `needs_regeneration` | 核心声源不可辨或错误，或技术/语义问题已使当前输出不适合作为有效结果，需要重新生成或重新取样。 |

最终决策以人工复听与 adjudicated 快照为准，不由任一单项分数或客观指标自动触发。

## 7. 责任边界

- 评测者亲自完成 200 条正式样本听评、隐藏重复复测与最终 Badcase 决策。
- 五层框架与 STFT/FFT、BS.1770 响度和人耳响度曲线方向由评测者提出。
- AI 辅助完成资料整理、重复样本提取、脚本执行、表格生成与交付物制作；评测者提出修改意见并审核结果。
